# 受信ユニット検査治具（波形表示アプリ）

検査基盤から UART（115200bps）で来る波形を表示し、チャンネル変更命令を送る。

## 動かし方
- `python main.py` … 起動する
- `python main.py --fake` … ハードなしで動かす。ポートの一覧に「FAKE」が出て、検査基盤のふり（`fake_board.py`）につながる
- `python -m PyInstaller --noconfirm main.spec` … `dist\main.exe` を作る

## 表示の決まり（ファームの出力をありのまま見せる）
- アプリは自動で合否を決めない。波形を見て、何が起きているかを人が見る
- 捨てるのは、パケットとして成り立たないものだけ（終了コード 0xFF が無い・チェックサムが合わない）。捨てたものは「化け」として数える
- 成り立っているパケットは、中身を加工せずに描く。ECG は仕様書どおり bit0〜bit10 を値とする（bit12 エラー・bit13 QRS のフラグは値に入れない）
  - 波形を切り替えた直後など、基盤に ECG が無いとき、基盤は bit12 だけを立てて値 0 を送る。そのあいだは −1024 に平らな線が出る（実機で 2 秒ほど）
  - データのバイトの bit7 は見ない（下位 7 ビットだけを使う。チェックサムも下位 7 ビット）
- 受信なし（1 秒来ない）になっても、波形は消さずに残す（止まる前に何が来ていたかを見られるように）。受信なしは上の表示と下の回数で分かる
- 「開始」を押すと、前の波形・CH・数は消す

## 実機での見え方（旧型 PC-053＋ダミーで確かめた。2026-10-23）
- 波形を切り替えると、2 秒ほど −1024 の平らな線 → なだらかな線（基盤のフィルターが落ち着くまで）→ 新しい波形。基盤エラーが 1 ほど増える
- 今と同じ波形のボタンを押しても、画面は変わらない。アプリは送るが、基盤は同じ CH が来ても何もしない（受信機のファーム `from_host.c`）。送り直しが効くのは、基盤の CH が変わってしまったとき（電源の入れ直しで 0 に戻ったときなど）
- 基盤 → ダミーの UART が切れていると、切り替えても「未同期」のまま、「同期済み」が点滅し、基盤エラーが増え続ける（基盤が CH の食い違いで同期をやり直し続けるため）
- ダミー → 基盤の SPI が切れると、−1024 の平らな線になる
- 基盤の電源を入れ直すと、通し番号が 0 から始まるので「抜け」が 1、止まっていたあいだの「受信なし」が 1 増える。同期し直すので基盤エラーも増える

## 下の数字（1 つでもあれば赤くなる。「開始」で 0 に戻る）
- 抜け … パケットの通し番号が前の +1 でなかった回数。開始コードが化けたパケットもここに出る。基盤の電源の入れ直しも 1 回と数える（番号が 0 から始まるため。電源が落ちたときの途中のパケットで、化けも 1 になる）。48 時間で番号が 0 に戻るのは数えない
- 化け … 開始コードはあったが、形の崩れていたパケットの数（チェックサム・終了コードの誤り、途中のバイトの抜け）。途中のバイトが抜けると、抜けも 1 になる。化けたバイトがたまたま開始コード（0xF0）になると、1 つのパケットで 2 と数えることがある
- 基盤エラー … 基盤がダミーから受けたフレームで、エラーと見たもの（CH の食い違い・パリティの誤り）の合計（パケットの ERR_CNT を足したもの）。基盤はエラーのフレームの ECG を前の値で埋めるので、波形には出にくい。波形を切り替えると、同期し直すあいだに良品でも増える（実機で 1 回の切り替えに 1 ほど）。どこまでを良しとするかは人が見て決める。1 パケットで 128 以上になると下位 7 ビットしか読めないが、5 回続けてエラーになると基盤が同期し直すので、届かない作り
- 受信なし … データが 1 秒来ずに「受信なし」になった回数（開始してから何も来ないときも 1 回）。基盤が止まって戻っても、後から分かる
- 合否はアプリが決めず、人が決める

## 試験
- `python -m unittest discover -s tests -v`
- `tests/test_view.py` は窓を作るので、画面のある PC で回す

## ファイル
| ファイル | 中身 |
|---|---|
| `main.py` | 入口 |
| `view.py` | 窓・開始と停止・送信・定期更新 |
| `view_control_panel.py` | 左の操作パネル（① ポート → ② 受信 → ③ 波形を送る） |
| `view_status.py` | 上の状態表示（受信・同期）と下の数字（CH・パケット・抜け・化け・基盤エラー・受信なし） |
| `view_wave_chart.py` | 波形表示（matplotlib。左から右へ上書き） |
| `jig_state.py` | 受信・同期・波形の状態と、抜け・化け・基盤エラー・受信なしの数を決める（画面には触らない） |
| `serial_reader.py` | COM ポートとパケットの切り出し |
| `packet.py` | パケットの項目の位置 |
| `fake_board.py` | 検査基盤のふり（試験と `--fake` 用） |
| `theme.py` | 色と文字 |
